# GlowUp

A make-up scanner for Android with AR try-on, and an admin website, sharing one Firebase project (`glowup-admin-portal`).
The app reads a product's label, checks its ingredients against the user's Skin Profile on the phone, recommends make-up with nothing flagged for
the user, and previews shades on the face. Admins keep the brand, product and ingredient lists on the website.
Informational only; not medical advice.

| Folder | What it is |
|---|---|
| `GlowUp/` | Unity 2022.3.62f3 project (C#, URP 14, AR Foundation / ARCore 5.2.2, ML Kit through Java plug-ins). Our code: `Assets/_Project/`, `Assets/Plugins/Android/GlowUp*.java` |
| `GlowUp-Admin_AI_Testing/` | Admin website: static HTML + ES modules, Firebase JS 10.12, deployed on Vercel (`glowup-admin`); two Vercel functions in `api/`; `firestore.rules`; checks in `tests/`; tools in `tools/` |
| `tools/ScannerEval/` | Measures the app's label reader (precision / recall) on labelled examples in `tests/fixtures/ingredient-labels/` |
| `docs/` | Architecture as found, data model, data source policy, admin guide, privacy notes, thesis alignment, agent report |

Start with `docs/ARCHITECTURE_AS_FOUND.md`. The database contract is `GlowUp-Admin_AI_Testing/FIRESTORE_SCHEMA.md`.

## Run the checks

| What | Command (from the repository root) | Needs |
|---|---|---|
| Website logic (13 files) | `npm test` | Node 18 or newer (24 used) |
| Security rules in the Firestore emulator (138 checks) | `npm --prefix GlowUp-Admin_AI_Testing/tests/rules install` once, then `npm run test:rules` | Java 11 or newer on the PATH (Unity's own JDK works: `<Unity>/Editor/Data/PlaybackEngines/AndroidPlayer/OpenJDK/bin`) |
| Emulator for trying the website | `npm run emulators`, then `npm run seed:dev` (dry run) or, with `FIRESTORE_EMULATOR_HOST=127.0.0.1:8085`, `node GlowUp-Admin_AI_Testing/tools/seedDev.mjs --write` | as above |
| App logic (NUnit) | Unity > Window > General > Test Runner > EditMode > Run All | Unity 2022.3.62f3 |
| Label reader accuracy | `npm run eval:scanner` | .NET 8 SDK, and the Unity project compiled once |

## Build and deploy

- **App**: open `GlowUp/` in Unity 2022.3.62f3. Scenes are generated by the builders (`GlowUp > Build Scene > All Scenes`); build an APK from Build Settings
  or `GlowUp > Build Android APK`. The file holding the app's AI key (`Assets/_Project/Scripts/Security/SecureProfileStore.cs`) is not in Git and must
  be copied in by hand.
- **Website**: from `GlowUp-Admin_AI_Testing/`, `npx vercel --prod`. Live at `https://glowup-admin-snowy.vercel.app`. The AI keys are Vercel
  environment variables (`GEMINI_API_KEY`, optional `GROQ_API_KEY`, `MISTRAL_API_KEY`); none is in the repository. The Firebase browser key only works
  from the website's addresses (Google Cloud > Credentials > Browser key > referrers): a new address must be added there, and in `KEY_REFERER`
  (`api/assist-ingredient.js`), before the site moves.
- **Security rules**: Firebase console > Firestore Database > Rules > paste `GlowUp-Admin_AI_Testing/firestore.rules` > Publish (after adding your
  account to `admins`, see `FIRESTORE_SCHEMA.md`).
