    As given by the source

    Kept exactly as read, so the list above can be compared with it. Text read from a photo can have misread letters.

    Shades

    The colours of the product (lips, cheeks, eyes, face). AR Try-On shows these shades. Brands print a shade CODE on the pack (such as 119 or N20), not a colour: type it in the Code box next to the colour, so the app finds the colour from the code it reads on a scanned pack.

    Listing

    The app does not recommend the product to younger users, and warns them if they scan it.

    Active: approved, the app shows it. Pending: saved for review; it waits in Waiting for review and the app does not show it. Inactive: switched off, kept in the inventory.
