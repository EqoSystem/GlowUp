Part B · The system at a glance4. System architecture

In plain words. There is no server of the team's own between the phone and the database. The phone app and the admin website both talk directly to Google Firebase: Authentication for sign-in and Cloud Firestore for data. Firestore's security rules are the gatekeeper. The phone keeps a copy of what it needs (catalogue, profile, history) and works from that copy first. Two small Vercel functions exist only to call the AI with a key that never reaches a browser or a phone. {V:Scripts/Data/FirebaseBootstrap.cs, Scripts/Data/OfflineCache.cs, GlowUp-Admin_AI_Testing/_Database/firebase-console.js, GlowUp-Admin_AI_Testing/api/*.js}
