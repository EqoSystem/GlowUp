What belongs where. App logic that has no Unity dependency (rules, parsers, index) is written as pure classes so it can be unit-tested; screen objects are never edited by hand but changed in the builder and regenerated; Android-only native code goes in Plugins/Android/GlowUp*.java; website logic shared by pages goes in _Shared/; anything secret goes in a Vercel environment variable, never in a file. {V:Scripts/Scan/ProductScope.cs "Pure logic", Editor/SceneBuilderCore.cs, CLAUDE.md, api/assist-ingredient.js header}
