Part D · Admin website18. How brands, products and ingredients are injected

There are six ways data reaches the database. None of them can make an entry live without an admin, except the admin's own form.

PathResult
1. Admin formsWritten as typed (Active if the admin chooses). {V:§17}
2. File import (PDF, Excel .xlsx/.xls, Word .docx)Text extracted in the browser; the GlowUp import format is parsed without AI, any other document is read by the AI function; records saved as Pending, source: document-import, reviewed: false. 18.1 The import pipeline, step by step

  1. Admin drops a file on "Import from a file" (Inventory: brands + products; Curator: ingredients). {V:adminBrandInventory.html line 92}
  2. adminDocumentReader.js extracts the text in the browser. {V:_Shared/adminDocumentReader.js}
  3. importFormat.js tries the plain format: blocks === BRAND ===, === PRODUCT ===, === INGREDIENT ===, KEY: value lines, lists with " | ", or an Excel sheet whose row 1 holds the keys. N/A, None and empty stay empty; nothing is guessed. {V:_Shared/importFormat.js header, IMPORT_FORMAT.md}
  4. Otherwise the text goes to /api/assist-ingredient (admin token checked) and the AI returns the same draft shape. {V:_Shared/importFormat.js header}
  5. Cleaning: whitespace collapsed; text cut to field limits; at most 40 products and 40 brands per file (ingredients saved in groups of 60); names de-duplicated by a comparable key; only https sources; shades only #RRGGBB (a shade number like "#128" is never a colour); minimum age 1-99 or 0. {V:adminBrandInventory.js lines 908-1000, IMPORT_FORMAT.md}
  6. Make-up check: skin care / not make-up records are flagged and not saved; unclear kinds are saved as Pending and flagged. {V:FIRESTORE_SCHEMA.md, adminBrandInventory.js}
  7. Duplicates: a product that already exists is skipped; if it has no ingredient list, the imported list (3+ names) goes to productIngredientSuggestions for review. {V:adminBrandInventory.js}
  8. Write in a batch; the page shows a summary (saved, duplicates skipped, invalid, FDA links, lists suggested) and the flagged records. {V:adminBrandInventory.js line 909-910}
  9. Admin reviews and approves each entry (status Active, reviewed true). {V:adminBrandInventory.js lines 2382-2423}

INCI names: ingredients are matched by name, technical (label) name and aliases through a normalised key (case, accents, punctuation and spaces ignored), and close misreadings are forgiven at a similarity of 0.85. There is no official INCI dictionary in the project. {V:Scripts/Data/TextKey.cs, Scripts/Scan/ScanRules.cs line 22} {N:an INCI / CosIng reference dataset in the repository}
