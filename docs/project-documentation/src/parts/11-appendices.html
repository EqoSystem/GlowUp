AppendicesAppendix C. Glossary

TermMeaning
INCIInternational Nomenclature of Cosmetic Ingredients: the standard ingredient names printed on cosmetics (e.g. "Aqua", "CI 77491").
OCROptical character recognition: turning a picture of text into text. GlowUp uses Google ML Kit on the phone.
ARAugmented reality: drawing virtual make-up over the live camera picture of the face.
ARCore / AR FoundationGoogle's AR service on Android / Unity's layer over it.
Face mesh / landmarkA 3-D surface (mesh) or set of points (landmarks) that follows the face; GlowUp uses ARCore's mesh.
EmbeddingA list of numbers that describes a picture; similar pictures give similar numbers.
MobileNet / MediaPipeA small image model / Google's on-device ML toolkit that runs it.
LLM / GeminiLarge language model; Gemini is Google's, used here with images and web search.
FirestoreGoogle's NoSQL document database in Firebase.
Security rulesServer-side conditions in Firestore that allow or refuse each read and write.
Collection / documentA named group of records / one record (JSON-like) in Firestore.
Vercel functionA small server program run on demand by the website host.
UNIIUnique Ingredient Identifier of the US FDA substance registry.
FDA PH notificationA cosmetic product's registration with the Philippine FDA before sale.
Argon2idA password-hashing method resistant to guessing attacks; used for offline log-in.
Skeleton loadingGrey placeholder bars shown where data will appear.
Umbrella termA label word such as "Fragrance" that can hide several undisclosed substances.
Pending / reviewedStatus of an entry that an admin has not yet approved / has checked.
IL2CPP, ARM64Unity's C#-to-C++ build; 64-bit ARM processors.
App CheckFirebase service that lets only genuine app/site builds call the backend (not used).
RA 10173Philippine Data Privacy Act of 2012.
