What was read, and what was not

  • Read: the Unity project's own code (GlowUp/Assets/_Project/: Scripts, Editor builders, tests, legal text), our Android Java files (Assets/Plugins/Android/GlowUp*.java by name), the admin website (GlowUp-Admin_AI_Testing/: pages, shared modules, api/ functions, tests, tools, firestore.rules, vercel.json, firebase.json, schema and import documents), the Git history (103 commits), CLEANUP_LOG.md, and the documents already in docs/.
  • Not read, on purpose: GlowUp/ProjectSettings/, GlowUp/Packages/, Library/, Plugins/ (except our Java file names), StreamingAssets/ and vendor SDK folders. The project's own rule (CLAUDE.md, .graphifyignore) excludes them. Package versions that live only there are marked Inferred from the methodology chapter in docs/, and Appendix D asks the team to confirm them from Packages/manifest.json.
  • The capstone paper itself is not in the repository. docs/GlowUp_Methodology_Replacement.pdf (a methodology chapter, 21 pages) is, and Part I compares it with the code. Appendix D asks the team for the full paper.
  • The live Firebase project and the live website were not contacted while writing this. "Deployed" or "published" is only stated where a commit message or file says so.

How paths are written

To keep citations short: paths that start with Scripts/, Editor/, Legal/, Shaders/, Materials/, Resources/ or Scenes/ are under GlowUp/Assets/_Project/. Paths that start with _Shared/, _Admin_, _Index/, _Database/, api/, tests/, tools/ or name firestore.rules, vercel.json, FIRESTORE_SCHEMA.md, IMPORT_FORMAT.md are under GlowUp-Admin_AI_Testing/. "Commit abc1234" means the Git commit with that id; "line N" refers to the file as of commit 87c6162 plus the working tree on 24 October 2026.

Words used for status

Built = the code exists. Checked = automated tests or the developer's local test rig ran it. Not proven on a phone = no record in the repository of a run on a real Android device. Most phone-side features are in the third group; Part J and Appendix D list them.
