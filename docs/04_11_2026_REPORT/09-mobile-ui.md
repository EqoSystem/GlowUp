# 09. Mobile app UI: scenes and traced controls

The project contains 15 Unity scenes under `GlowUp/Assets/_Project/Scenes/`. Scene controllers expose serialized Unity `Button`, input and toggle fields; the actual objects and click wiring are stored in the scene assets. A control is described below where its behavior is visible in the controller. **PARTIALLY TRACED** means the scene exists but a complete control-by-control path could not be established from the inspected scene/controller evidence.

## Data contracts referenced by screens

User profile data includes name, email, birthday/age, skin type/tone, conditions and allergens. Scan records include product identity, ingredient list/findings, verdict, compatibility results, source attribution and history metadata. These model fields are in `GlowUp/Assets/_Project/Scripts/Data/DataModels.cs`. The screen documentation does not imply that each screen writes every field.

## Scene-level trace limits

All 15 scene files are present, but not every serialized GameObject/UnityEvent in every scene has been independently inspected in this chapter. The scenes explicitly labeled **PARTIALLY TRACED** need a scene hierarchy and serialized-reference audit to claim every visible button, toggle, input, and event target.
