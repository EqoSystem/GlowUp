# 06. API keys, secrets and configuration locations

No secret values are included in this chapter. The table gives only source location, variable/config name, loading path and client/build exposure. Names are included because they are required to locate configuration; none of their values are reproduced.

| Purpose | File / variable name | Where it is loaded | Client or mobile build exposure |
|---|---|---|---|
| Mobile Gemini scan API credential | `GlowUp/Assets/_Project/Scripts/Security/SecureProfileStore.cs`; method `GetApiKey()` (no environment-variable name) | Returns a string from compiled C# code; consumed by the Gemini scan path (`Scanning/Geminiapiclient.cs`). | **Ships inside the mobile app build.** The value is compiled into client code and is recoverable from the app. |
| Mobile Gemini endpoint/model configuration | `GlowUp/Assets/_Project/Scripts/Scanning/Geminiapiconfig.cs`; `ApiBaseUrl`, `ModelChain`, timeout/retry settings | Unity `ScriptableObject` settings read by the scan client. | Endpoint/model settings are client-visible and packaged as Unity app data. |
| Firebase Android app configuration | `GlowUp/Assets/google-services.json` | Firebase Android/Unity integration processes this project configuration during Android builds. | Android Firebase project configuration is client-side. Whether every source field is emitted into the final APK is **NOT FOUND IN CODE**; it must not be treated as a server secret. |
| Web Firebase client configuration | `GlowUp-Admin_AI_Testing/_Database/firebase-console.js`; `firebaseConfig.apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId` | Imported by every admin page's JavaScript module. | **Exposed in the website bundle/browser** by design. Firebase API key is a client identifier, not an authorization secret; rules and API restrictions are the security boundary. |
| Vercel Gemini credential | `GEMINI_API_KEY` (with `GLOWUP_WEB_AI` alias) | Vercel environment in `api/assist-ingredient.js`; server-side only. `api/scan-snapshot.js` uses the same server-side key configuration. | Not embedded in the admin website or mobile build by these functions. Sent to the AI provider from Vercel server code. |
| Optional AI provider credentials | `GROQ_API_KEY`, `MISTRAL_API_KEY`, optional `OPENROUTER_API_KEY` | Vercel environment read by `api/assist-ingredient.js`; fallback provider calls are server-side. | Not intended for client exposure. **NOT FOUND IN CODE** whether these variables are configured in the live Vercel project. |
| Optional provider model selectors | `GEMINI_MODELS`, `GROQ_MODEL`, `MISTRAL_MODEL`, `OPENROUTER_MODEL` | Vercel environment read by `api/assist-ingredient.js`. | Server-side configuration; not client bundle values. |
| Archive cron bearer secret | `CRON_SECRET` | Vercel environment read by `api/archive-purge.js`, compared against the request authorization header. | Server-side only; not included in website/mobile source. |
| Firestore purge service account | `FIREBASE_SERVICE_ACCOUNT` | One-line JSON environment variable read by `api/archive-purge.js`; used to sign a JWT and request Firestore access tokens. | Server-side only; never put in the website bundle or mobile build. |
| Archive purge behavior and cap | `ARCHIVE_PURGE_LIVE`, `ARCHIVE_PURGE_MAX` | Vercel environment read by `api/archive-purge.js`; dry run is the default and maximum is capped in code. | Server-side operational settings. |
| Firebase API key used by Vercel identity checks | `FIREBASE_WEB_KEY` constant in `api/assist-ingredient.js` (shared by snapshot helper) | Included in server function source and used to ask Firebase Identity Toolkit to validate a Firebase ID token. | A Firebase web API key is not a private credential; client-visible project key is separately in the website bundle. |
| HTTP referrer restriction value | `KEY_REFERER` in `api/assist-ingredient.js` | Server-side request header used by identity validation. | Public endpoint/address configuration, not a credential. |
| Vercel project/route/schedule config | `GlowUp-Admin_AI_Testing/vercel.json` | Vercel deployment config. | Public behavior/configuration; no secret values. |
| Firestore emulator address | `GlowUp-Admin_AI_Testing/firebase.json` | Firebase CLI/emulator configuration. | Local development configuration. |

The mobile Gemini credential is the key most directly at risk because source code packages it into the client. The admin AI key and purge service-account credential are designed to live in Vercel environment variables only. This table describes source-defined loading locations, not whether a deployment's environment variables are currently populated. No `.env` values or credential values are reproduced.
