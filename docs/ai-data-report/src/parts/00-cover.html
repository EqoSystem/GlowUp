How paths are written

Paths that start with Scripts/, Editor/, Shaders/, Materials/ or Legal/ are under GlowUp/Assets/_Project/. Paths that start with _Shared/, _Admin_, api/, tests/, tools/, or name firestore.rules, FIRESTORE_SCHEMA.md, IMPORT_FORMAT.md, are under GlowUp-Admin_AI_Testing/. "Line N" means the file as of 26 October 2026.

What was read

  • Read: the app's own code (GlowUp/Assets/_Project/), the admin website (GlowUp-Admin_AI_Testing/), firestore.rules, the schema and import documents, and the Git history.
  • Not read: Library/, Plugins/ (except our own Java file names), StreamingAssets/ and SDK folders, as the project's CLAUDE.md asks. For the Unity version and AR package versions, three setting lines and the package names were looked up once (Unity 2022.3.62f3, AR Foundation and ARCore XR Plugin 5.2.2, URP 14.0.12); every other build setting is cited from the Editor scripts that set it.
  • The live Firebase project and the live website were not contacted. Nothing was deployed.

Words used for status

Built = the code exists. Checked = automated tests or a desktop check ran it. Not proven on a phone = no record of a run on a real Android phone. Most phone-side features are in the third group.
