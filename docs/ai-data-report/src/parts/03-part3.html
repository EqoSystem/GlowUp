11. Links to dermatology and pharmacology references

  • How a description links to a reference: each ingredient keeps sources[] as "page title | https://address". The kind of page (regulator, medical, maker, reference, public, retailer, other) is worked out when shown, by one rule in the app, the website and the server, tested against shared cases. {V:FIRESTORE_SCHEMA.md lines 195-213; Scripts/Scan/ListSources.cs SourceKind; _Shared/glowupRules.js sourceKind}
  • How a link is validated: only plain https:// addresses are shown as links; an address with a user name in front, a backslash or odd characters is labelled "Unverified site" and never shown as a link. Assist with AI keeps only links that were printed in the document or opened by its web search. {V:FIRESTORE_SCHEMA.md lines 67, 207}
  • When a link breaks: nothing checks old links. {N:a periodic link checker for sources and image links} The entry keeps its text; the user can still read the title.

12. Source hierarchy when sources disagree

The app already has an order of trust for one product's list, best first: (1) the user's own pack read by the camera, (2) the GlowUp inventory, (3) the brand's official site or store, (4) a large retailer's copy, (5) Open Beauty Facts, (6) any other page that can be shown. Ingredient databases (CosIng, INCI Decoder, EWG) explain ingredients but are never the source of one product's list. {V:Scripts/Scan/ListSources.cs lines 8-21}

How a conflict is recorded: two lists agree when 85% of the longer list matches (at least 4 names; colourant numbers and "may contain" names left out). The scan keeps listCheck = "matched" or "differs", which second place it was, its date, how many names differ, and a few names on each side. The shown list never changes because of the second source. {V:Scripts/Scan/ListSources.cs lines 350-352, 433-444; Scripts/Data/DataModels.cs lines 183-189}

Suggested rule for admins (to adopt): current pack in hand > manufacturer page for the same country > FDA Philippines record (for identity, not the list) > large retailer page > Open Beauty Facts > anything else. When two disagree, keep the higher one, put the other in sources with the date, and write the difference in the product's description until a pack is checked.
